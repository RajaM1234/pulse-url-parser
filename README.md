# 🚀 Page Pulse

Page Pulse is a full-stack web application that analyzes websites and provides useful SEO and content insights. Users can submit a website URL and instantly receive information such as page title, meta description, heading statistics, image alt text analysis, response time, and word count.

---

## ✨ Features

- 🔍 Analyze any valid website URL
- 📄 Extract page title
- 🏷️ Extract meta description
- 📝 Count headings (H1–H6)
- 🖼️ Analyze image alt text statistics
- 📊 Word count analysis
- ⚡ Measure website response time
- ❌ Handles invalid and unreachable URLs gracefully
- 🧪 Backend API testing with Jest & Supertest
- ✅ GitHub Actions CI for automated testing
- ☁️ Deployed with Render and Vercel

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/RajaM1234/pulse-url-parser.git
cd pulse-url-parser
```

### Backend Setup

```bash
cd page-pulse/server
npm install
npm start
```

### Frontend Setup

```bash
cd page-pulse/client
npm install
npm run dev
```

---

## 🧪 Running Tests

```bash
cd page-pulse/server
npm test
```
